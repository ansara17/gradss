# The Chapter You Earned

Kartu kelulusan digital untuk Amel. Buka `index.html` di browser untuk melihatnya.

## Isi folder
- `index.html`, `style.css`, `script.js`: halaman, tampilan, dan interaksi kartu.
- `assets/photos/amel.jpg`: foto Amel dari proyek sebelumnya.
- `assets/music/background-music.mp3`: musik latar dari proyek sebelumnya.

Agar foto dan musik tampil, pertahankan struktur folder `assets` saat memindahkan atau mengunggah kartu.
