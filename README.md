# The Chapter You Earned — Pressed Flower Journal

Kartu kelulusan digital untuk Amel. Buka `index.html` di browser untuk melihatnya.

## Isi folder
- `index.html`, `style.css`, `script.js`: halaman, tampilan, dan interaksi kartu.
- `assets/photos/amel.jpg`: foto Amel.
- `assets/music/background-music.mp3`: musik latar.
- `assets/pressed-flower-sprig.svg`: ornamen floral herbarium.

Pertahankan struktur folder `assets` saat memindahkan atau mengunggah kartu.
